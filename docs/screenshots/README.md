# 소개 페이지 스크린샷

`docs/index.html`의 "앱 화면 미리보기" 섹션에 표시되는 스크린샷입니다.

| 파일 | 화면 | 비고 |
|------|------|------|
| `home.png` | 홈 대시보드 | 데스크탑 가로 |
| `ai-planner.png` | AI 여행 플래너 | 모바일 세로 (`is-portrait` 적용) |
| `map.png` | 인터랙티브 지도 | 데스크탑 가로 |
| `start.png` | 시작 화면 | 데스크탑 가로 |
| `login.png` | 로그인 | 데스크탑 가로 |

원본은 `public/images/`에 동일 파일명(공백 포함은 `ai planner.png`)으로 보관되며,
GitHub Pages 호환을 위해 이 폴더에 복사본을 둡니다.

## 권장 사항

- **형식**: PNG (다른 확장자를 쓰면 `docs/index.html`의 `<img src="...">` 경로도 함께 수정)
- **비율**: 카드는 16:10 가로 비율로 표시됩니다.
  - 데스크탑 가로 스크린샷은 위쪽 기준으로 크롭되어 채워집니다(`object-fit: cover`).
  - 모바일 세로 스크린샷은 `is-portrait` 클래스로 전체 화면이 가운데 정렬로 표시됩니다.
- **용량**: 카드당 300KB 이하 최적화 권장 (현재 일부 파일이 1MB+ 이므로 압축 권장)
